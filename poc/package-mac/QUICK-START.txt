  MedVerse Scientific Intelligence Ecosystem
  Mac Quick Start Guide — POC v0.4
═══════════════════════════════════════════════════════════════


  STEP 1: UNZIP
  ─────────────
  Double-click the downloaded MedVerse-Mac-v0.4.zip file.
  macOS will create a "MedVerse-Mac-v0.4" folder automatically.

  You can move this folder anywhere you like — Desktop,
  Documents, or Downloads all work fine.


  STEP 2: FIRST-TIME SETUP (one time only)
  ─────────────────────────────────────────
  The first time you run MedVerse, macOS may block it because
  it came from the internet. To fix this:

    a) Open Terminal (press Cmd + Space, type "Terminal", Enter)

    b) Type this command (adjust the path if you moved the folder):

         chmod +x ~/Downloads/MedVerse-Mac-v0.4/start-medverse.command

    c) Close Terminal. You won't need it again.

  ALTERNATIVELY: Right-click "start-medverse.command" and choose
  "Open". When macOS asks if you're sure, click "Open" again.


  STEP 3: LAUNCH
  ──────────────
  Double-click "start-medverse.command"

  A Terminal window will open showing the server status,
  and your default browser will open MedVerse automatically.

  That's it! MedVerse is now running.


  STEP 4: USE
  ───────────
  • Navigate between modules using the top tabs:
    MSL Copilot, Medical Concierge, HCP Concierge,
    Patient Concierge, Power Agents, Demo

  • Click "Run Demo" on any page for a narrated walkthrough

  • Use the search bar (or tap the microphone for voice search)

  • Click "Demo" in the nav bar for the master demo with
    Play All mode across all modules


  STEP 5: STOP
  ────────────
  Close the Terminal window, or press Control + C in Terminal.

  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

  "Cannot be opened because it is from an unidentified developer"
  → Right-click the file → Open → Click "Open" in the dialog

  "Permission denied"
  → Open Terminal and run:
    chmod +x ~/Downloads/MedVerse-Mac-v0.4/start-medverse.command

  "Python not found"
  → macOS 12.3+ removed Python 2. Install Python 3:
    Go to python.org/downloads, download, and install.
    Restart your Mac, then try again.

  "Port 8080 already in use"
  → MedVerse automatically tries ports 8081, 8082, and 3000.
    Check the Terminal window for the actual URL.

  "PubMed / ClinicalTrials.gov search not working"
  → These features require the local server AND internet.
    Make sure you launched via start-medverse.command
    (not by opening index.html directly).

  Browser didn't open automatically?
  → Open Safari or Chrome and go to: http://localhost:8080
