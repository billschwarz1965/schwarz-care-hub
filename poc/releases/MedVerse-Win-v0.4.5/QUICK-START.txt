===============================================================
  MedVerse Scientific Intelligence Ecosystem
  Windows Quick Start Guide — POC v0.4.5
===============================================================


  STEP 1: UNZIP
  -------------
  Right-click the downloaded MedVerse-Win-v0.4.5.zip file
  and choose "Extract All..." (or double-click to open).

  Move the extracted "MedVerse-Win-v0.4.5" folder anywhere
  you like — Desktop, Documents, or a shared drive.


  STEP 2: LAUNCH
  --------------
  Double-click "Start-MedVerse.bat"

  A command prompt window will appear showing the server
  status, and your default browser will open MedVerse
  automatically.

  That's it! MedVerse is now running.

  NOTE: If Windows SmartScreen shows a warning, click
  "More info" then "Run anyway" — this is normal for
  scripts downloaded from the internet.


  STEP 3: USE
  -----------
  * Navigate between modules using the top tabs:
    MSL Copilot, Medical Concierge, HCP Concierge,
    Patient Concierge, Power Agents, Demo

  * Click "Run Demo" on any page for a narrated walkthrough
    (make sure your speakers or headphones are on)

  * Use the search bar or tap the microphone icon for
    voice search (requires Chrome or Edge)

  * Click "Demo" in the nav bar for the master demo with
    Play All mode across all modules


  STEP 4: STOP
  ------------
  Close the black command prompt window, or press Ctrl+C.


  OPTIONAL: SHAREPOINT ONE-CLICK LINK
  ------------------------------------
  For team distribution via SharePoint:

    1. Double-click "Install-MedVerse.bat" (one time only)
    2. This registers the medverse:// URL protocol
    3. Create a link on SharePoint: medverse://launch
    4. Anyone who clicks the link opens MedVerse instantly

  Each user needs to run Install-MedVerse.bat once from
  their own copy of the package. No admin rights needed.


===============================================================
  TROUBLESHOOTING
===============================================================

  "Windows protected your PC" (SmartScreen)
  -> Click "More info" then "Run anyway"

  "Running scripts is disabled on this system"
  -> The .bat launcher handles this automatically by using
     -ExecutionPolicy Bypass. If it still fails, right-click
     Start-MedVerse.bat and choose "Run as administrator".

  "Port 8080 already in use"
  -> MedVerse automatically tries ports 8081 and 8082.
     Check the command prompt window for the actual URL.

  "PubMed / ClinicalTrials.gov search not working"
  -> These features require the local server AND internet.
     Make sure you launched via Start-MedVerse.bat
     (not by opening index.html directly in a browser).

  Browser didn't open automatically?
  -> Open Chrome or Edge and go to: http://localhost:8080

  Voice search not working?
  -> Voice search requires Chrome or Edge (not Firefox).
     Allow microphone access when prompted by the browser.
