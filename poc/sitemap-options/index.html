Three ways to structure the US site map

Three clickable prototypes of the same US instance, each built on a different global-portal architecture from the Portal Structure deck. Every prototype shares the identical local /en-us depth — Therapeutic Areas, the Disease State layer, Programs, Events, Resources — only what sits above it at the global root differs.

What stays the same across all three: the local instance itself — Immunology → Type 2 Inflammation → specific-disease articles, Rare Blood Disorders as a US-only standalone TA, the Vaccines population hubs, the IMMERSE/ADVENT/Bridge/RD University/Nerve Nexus program brand pages, and the brand-first-vs-topic-first navigation split. Open any prototype and click "Continue to United States site" to reach it.
OPTION 1

Global portal, flat sections

medical.campus.sanofi/diabetes
— not nested under a TA folder

A gated global portal exists at the root. Global Therapeutic Area content sits directly off root as flat top-level sections. One shared global e-learning branch covers every program and TA together.

BEST FIT IF
globally-approved, unbranded TA content should be highly visible without digging into a specific country.
No direct precedent among the sites reviewed.

OPTION 2

Global portal, TA-nested

medical.campus.sanofi/diabetes/bridge
— nested under TA, same as local

A gated global portal exists at the root. Global programs nest under their Therapeutic Area even at the global level — the same pattern the local instance uses everywhere.

BEST FIT IF
IMMERSE-style tiered programs need identical structure whether global or local, and TA is always the organizing layer.
Closest to the original "Global vs. Local Architecture" spec and the first version of this workbook.
Open Option 2 prototype →
OPTION 3

No global portal

medical.campus.sanofi
— landing page + country selector only

No global program or TA content at all. The root domain is purely a routing page into a local instance, gated on HCP self-attestation plus a country selection.

BEST FIT IF
most content genuinely can't be approved globally anyway, so a global tier adds little payoff.
Matches adventprogram.com's actual live pattern today.
