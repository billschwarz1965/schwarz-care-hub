MedVerse — Local Editions Launcher

Five editions of the MedVerse POC, each its own Vite dev server on its own port, all sharing one copy of the application logic in poc/src.

Opened as a static file, so this page can only link to servers you start yourself — it can't start them for you. To start servers with the buttons below, run node launcher-server.mjs from a terminal in this folder, then open http://localhost:5199 instead of this file.
