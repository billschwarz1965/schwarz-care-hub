| File | Purpose |

**Use the CSV for facts and AI lookup; use the Complete document for depth and context.** When they diverge, update both in the same commit.

## Format

CSV with `SECTION,CONTENT` rows. Section headers are rows where CONTENT is empty or SECTION names a category.

## Update rules

1. Edit the CSV directly (Excel or text editor).
2. Update the header line: `Last Updated: YYYY-MM-DD`.
3. Register significant new source documents in [`../sources/registry.md`](../sources/registry.md).
4. Do **not** maintain parallel truths in markdown — extract facts here.
